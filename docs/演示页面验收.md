# HTML 演示页面验收记录

日期：2026-09-21。范围：原生 HTML/CSS/JavaScript 演示原型，不含真实气象接口与公开部署。

## 实际完成的检查

- 使用 Node.js 对 `app.js` 与 `scripts/serve.mjs` 进行语法检查。
- 使用本机 Playwright 与 Microsoft Edge 无头浏览器验证两台风切换，确认风力、路径标题同步改变。
- 检查六个路径时间点；关闭预报图层后隐藏预报并将选中的未来点恢复为模拟定位点。
- 检查风圈开关、放大与复位。
- 检查五个地区场景：蓝、黄、橙、红模拟预警以及地区数据未接入。
- 检查数据说明弹窗：内容内部点击保持打开，确认按钮、Escape 与遮罩点击可关闭。
- 在 1440px、390px、320px 宽度截图并检查无横向溢出；人工查看桌面与手机截图。
- 确认页面无 JavaScript 运行错误、无外部数据请求，直接使用 `file://` 打开时能渲染模拟预警。

检查脚本与截图位于被 Git 忽略的 `.cache/`，属于本机验证材料。浏览器自动检查使用了本机已安装的 Playwright，不是仓库生产依赖。

## 限制

尚未进行真实用户试用、生产负载测试、真实预警时效与地区映射验证、多浏览器兼容性认证或屏幕阅读器人工验收。页面的地图背景无真实地理比例和行政边界，风圈不表示实际影响范围。

页面内显著标记演示模式；虚构台风、地区信号和固定时间不作为防灾判断依据。
