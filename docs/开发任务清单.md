## M1：试点和数据

- [ ] 确定试点市与区县、预算及运营责任人。
- [ ] 确认正式数据授权、接口文档、测试账号和服务时效。
- [ ] 用一轮实况、一轮预报和一组预警修订完成字段对照。
- [ ] 确认地方预警规则、行政区域映射和地图底图许可。
- [ ] 完成手机版线框及目标居民评审。

完成条件：能证明所需核心数据可合法获取并展示；否则只能继续模拟原型。

## M2：数据服务与基础页面

- [ ] 初始化前后端与锁定依赖版本，补充运行说明。
- [ ] 实现来源适配、时区/单位校验、缺失值、数据状态和缓存。
- [ ] 实现台风切换、四张核心信息卡和地区选择。
- [ ] 实现来源链接、业务时间及正常/延迟/不可用显示。

完成条件：同一时次的页面字段与授权样本逐项一致，浏览器无接口密钥。

## M3：地图与预警

- [ ] 区分历史路径与预报路径，提供地图的文字替代。
- [ ] 按区域展示官方预警，并保留原文、机构和修订关系。
- [ ] 覆盖升级、降级、继续、解除、到期、重复和乱序事件。
- [ ] 覆盖特殊地方等级、多台风、无台风与地区尚未覆盖状态。
- [ ] 实现数据异常降级，不把空数据当作解除或安全。

完成条件：预警事件回放与区域匹配验收通过。

## M4：试运行

- [ ] 完成移动端、键盘、色彩可辨性、定位拒绝及弱网检查。
- [ ] 完成 5—8 名目标用户试用，记录查找时间与误解点。
- [ ] 按试点规模测试性能、负载、缓存和上游故障恢复。
- [ ] 配置监控、备份、运营联系方式和错误更正流程。
- [ ] 确认授权、来源标注、托管安排和生产数据隔离后发布。

完成条件：计划书验收项有记录，关键问题已处理，运营责任已落实。
