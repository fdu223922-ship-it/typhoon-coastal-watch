# 沿海台风通 · Typhoon Coastal Watch

面向沿海居民的台风实况与官方分级预警网站项目。

让居民快速回答：**台风叫什么、现在在哪、往哪走、风力多大，以及我所在地区发布了什么预警。**

## 当前阶段

2026-09-21：已完成项目规划与 HTML 演示原型。页面包含台风实况面板、SVG 路径示意、地区分级预警和数据说明，全部使用虚构演示数据；尚未接入真实接口或部署公开网站，不能作为正在运行的气象服务使用。

## 查看演示

直接用浏览器打开 [index.html](index.html) 即可，页面无需安装依赖，也不加载外部字体、地图或气象数据。

也可在仓库目录使用 Node.js 启动本地预览：

```sh
npm run dev
```

然后访问 `http://127.0.0.1:8016/`。端口被占用时，可设置 `PORT` 环境变量；服务仅监听本机。`npm run check` 检查 JavaScript 语法。没有构建步骤，HTML、CSS、JavaScript 都是直接运行的源文件。

### 已实现的演示交互

- 两个虚构台风切换，同步更新名称、位置、方向、风力与路径。
- 路径时间轴、模拟历史/预报区分、图层开关、缩放复位和文字数据表。
- 五个预设地区场景，展示蓝/黄/橙/红模拟预警及“数据未接入”状态。
- 数据说明弹窗、键盘操作、移动端布局和明显的演示标记。

地区预警独立于台风选择，属于预设情景，不能推断为某个台风造成的实际预警。所有时间固定于虚构场景，不会自动更新为当前时间。

### 文件职责

| 文件 | 用途 |
| --- | --- |
| `index.html` | 页面结构、SVG 抽象背景、演示提示和数据说明 |
| `styles.css` | 海绿色看板视觉、响应式与无障碍样式 |
| `app.js` | 虚构台风及地区数据、路径绘制、交互逻辑 |
| `scripts/serve.mjs` | 仅提供页面所需四个资源的本地预览服务 |

本阶段采用无依赖 HTML/CSS/JavaScript，便于直接打开；计划书中的 Vue/后端架构仍是后续正式数据服务的拟议方案。

## 核心原则

1. 台风中心风力、当地风力、当地预警分别展示。
2. 使用官方发布的预警信号，不以距离或台风强度自动生成官方预警。
3. 每条动态信息标注来源、业务时间和数据状态；缺失与过期不能显示成“安全”。
4. 手机优先；地图不可用时仍能阅读关键文字信息。
5. 正式上线以数据授权、试点地区规则核验和应急值守准备为前提。

仓库暂不选择开源许可证；公开可见不等同于授予第三方数据的再分发权限。
